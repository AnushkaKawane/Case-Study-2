# Case Study 2 - Perfume Recommendation System

A machine-learning based perfume recommendation web application.

## Features

- Search/select a perfume
- Find similar perfumes
- Uses TF-IDF vectorization
- Uses cosine similarity
- Displays perfume ratings
- Displays fragrance accords and notes
- Flask backend
- Vercel deployment ready

## Dataset

The project uses:

`parfumo_data.csv`

## Technologies

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript
